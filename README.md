# kospi200-vol-surface

KOSPI200 옵션 시장가격으로 만기별 SABR을 calibration하고, 차익거래 없는 연속 변동성 곡면을 만듭니다. 이 곡면으로 local vol을 만들어 실제 발행된 ELS를 Monte Carlo로 평가하는 것까지가 목표입니다.

> 코드와 결과는 학회 과제 마감 뒤에 공개합니다. 1주차(SABR 곡면)는 **2026-10-03 13:00 이후**, 2주차(local vol, ELS)는 2주차 과제 마감 이후입니다. 지금은 설계만 적어 둡니다.

## 과제 개요

U.FE.A 금융공학 학회 2026년 하반기 10·11주차에 이어지는 2주 과제입니다. 팀장으로서 과제를 설계했고, 이 저장소에는 그 해답을 정리해 올릴 예정입니다.

앞선 과제들은 변동성 하나를 주어진 값으로 썼습니다. 이 과제는 시장가격에서 행사가와 만기마다 다른 변동성(smile, term structure)을 직접 읽어 냅니다.

| 주차 | 내용 |
|---|---|
| 1주차 | 기준일 2026-09-14 KOSPI200 옵션으로 만기별 SABR(β = 1) calibration, T = 0 ~ 3.1년, K/S0 = 0.35 ~ 1.30 범위의 연속 곡면, 차익거래 점검 |
| 2주차 | 1주차 곡면으로 Dupire local vol을 만들고 미래에셋증권 제38133회 ELS(기초자산 KOSPI200)를 Monte Carlo로 평가 |

곡면의 범위는 이 ELS의 만기와 낙인 수준을 덮도록 정했습니다.

## 데이터

- 옵션·선물: KRX KOSPI200 선물·옵션, 2026-09-14 주간 거래. 종가를 쓰고, 체결이 없으면 익일정산가를 씁니다.
- 할인곡선: CD 91일과 국고채 1·2·3·5년 par yield로 부트스트랩합니다.
- 필터: OTM 옵션, 가격 > 0.05, 미결제약정 > 0, K/F ∈ [0.35, 1.30].

KRX 원자료와 가공 CSV는 저장소에 넣지 않습니다. 공개 후에는 KRX에서 직접 받은 원자료를 가공 CSV로 바꾸는 전처리 스크립트만 둡니다. 논문과 ELS 투자설명서도 저작권 때문에 넣지 않습니다.

## 방법 개요

1. **SABR 근사식.** Hagan et al. (2002)의 implied vol 근사식에 β = 1을 넣어 구현합니다. 가격 계산 라이브러리는 쓰지 않습니다.
2. **만기별 calibration.** 관측 가능한 4개 만기(2026-11, 2026-12, 2027-01, 2027-03)마다 시장 implied vol에 맞는 (α, ρ, ν)를 찾습니다. 그 전에 각 만기의 forward를 정해야 합니다.
3. **연속 곡면.** 관측 만기 사이는 total variance 선형 보간으로 잇고, 시장 데이터가 없는 6개월 이후 구간은 가정으로 외삽합니다.
4. **차익거래 점검.** calendar와 butterfly 위반을 격자 전체에서 셉니다. 완성된 곡면은 위반이 0건이어야 합니다.
5. **해석.** 만기별 변동성 기간구조를 두 가지 척도로 비교합니다.

### 과제 설계에서 신경 쓴 점

코드 양은 적게 하고, 단계마다 데이터와 투자설명서를 보고 판단해야 하는 지점을 두었습니다. 학생이 정하는 값은 두 개이고, 각 단계 뒤에 assert 검증 셀이 있어서 판단이 틀리면 통과하지 못합니다. 문제 설명만 보고 생성형 AI로 그대로 코드를 짜면 걸리도록 만든 함정도 있습니다. 구체적인 판단 내용과 결과는 마감 뒤에 적습니다.

## 개발 방식

과제 설계, 데이터 가공, 해답 노트북은 직접 작성했습니다. 포트폴리오 정리에는 Claude Code를 쓰고 있습니다. 공개 전 단계인 지금은 이 README만 올립니다. 해답을 모듈로 옮길 때는 원래 노트북 출력과 숫자가 같은지 대조하고, 곡면의 차익거래 위반 0건과 커브의 입력 재현을 pytest로 확인할 계획입니다.
